ShrinkWatch EU

Stop doing price per kg math. See the real price per kg or litre on supermarket web shops, and get a warning when a pack shrinks but the price stays the same.

Install in 1 minute Source on GitHub

Install in 1 minute

Free, no account. It is not in the browser stores yet, so you install it from a zip file:

  1. Download shrinkwatch-chrome-*.zip or shrinkwatch-firefox-*.zip from the latest release.
  2. Chrome / Edge / Brave: unzip it, open chrome://extensions (or edge://extensions), turn on Developer mode and click "Load unpacked".
  3. Firefox: open about:debugging#/runtime/this-firefox, click "Load Temporary Add-on" and pick the zip.

Listings on Firefox Add-ons and Microsoft Edge Add-ons are planned. Until then, the release zip is the way to install.

What it does

Unit price on every product
Shows €/kg, €/l or price per piece, even when the shop doesn't. Works with euros and with CZK, HUF, PLN, RON, SEK, DKK, RSD and BAM.
Shrinkflation warning
Remembers pack sizes you've seen, so if 500 g becomes 450 g for the same price, you see "+11.1% per kg".
Price history
The popup shows how the unit price of the product you're viewing has changed.
Private by design
No account, no server, no tracking. Everything stays in your browser.

Others ask for access only when you switch them on.
