# FAQ

Answers to the questions people ask most about ShrinkWatch EU. For install steps and the list of shops, see the [README](../README.md).

## My shop is not listed

Open a product page and click "Check this page now" in the popup. If that works, please [request the shop](https://github.com/emirmrkaljevic/shrinkwatch-eu/issues/new?template=shop-request.yml) so it can be added.

## The badge shows the wrong size or price

Please [report it](https://github.com/emirmrkaljevic/shrinkwatch-eu/issues/new?template=wrong-result.yml) with the product link.

## How does it work out the pack size?

It reads the whole pack, not just the first number, uses drained weight when a can lists one, and can show a price per piece for count packs. If a size looks wrong, please [report it](https://github.com/emirmrkaljevic/shrinkwatch-eu/issues/new?template=wrong-result.yml) with the product link.

## Why does the popup ask for permission on some shops?

Only a few shops are enabled by default. Any other shop is switched on only when you click "Enable on this shop", so the extension never gets access to sites you don't use.

## Does it send my data anywhere?

No. Pack sizes and prices are stored only in your browser.

## Can I move my history to another browser?

Yes. In the popup, click "Back up or restore history" to export it as a JSON file, then import that file in the other browser.

## Is a shrinkflation warning proof?

No. It compares what this browser saw before with what the shop shows now. Shop data can be wrong, so check the pack before drawing conclusions.

The website has a [longer FAQ](https://emirmrkaljevic.github.io/shrinkwatch-eu/faq.html) and a page on [what shrinkflation is](https://emirmrkaljevic.github.io/shrinkwatch-eu/shrinkflation.html).
